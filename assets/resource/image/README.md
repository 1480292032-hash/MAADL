# 模板图片目录说明

本目录存放模板匹配（TemplateMatch / FeatureMatch）用的识别素材，按游戏界面分子目录：

```
image/
├── common/    # 通用素材：弹窗关闭按钮、网络重连按钮、返回按钮等
├── main/      # 主界面：入口按钮、功能图标
├── story/     # 剧情推图：关卡选择、开始战斗、自动战斗按钮、结算、下一关、体力不足弹窗
└── daily/     # 日常：签到、邮件、在线奖励、每日副本
```

## 制作规范（重要）

1. 模拟器分辨率固定 **1280x720（DPI 240）**
2. 用模拟器自带的截图功能或 MaaDebugger 截**完整全屏图**
3. 全屏截图需为 1280x720 原始尺寸（不要缩放、不要裁剪后再截）
4. 从全屏图中裁剪出要识别的小图（按钮、图标、文字区域），**不要改变像素内容**
5. 文件名用有意义的英文命名，如 `story/btn_start_battle.png`
6. 建议 PNG 无损格式

## 在流水线中使用

```jsonc
"剧情_开始战斗": {
    "recognition": "TemplateMatch",
    "template": "image/story/btn_start_battle.png",
    "roi": [640, 360, 640, 360],   // 限定搜索区域可大幅提升速度
    "action": "Click"
}
```
